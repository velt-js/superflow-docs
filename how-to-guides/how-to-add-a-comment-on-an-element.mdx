---

In this article, you will learn how to add comments on an element using the Superflow Toolbar.

<Steps>
  <Step title="Find the Superflow Toolbar and click the Comment icon">
    <Frame>
    ![Find the Superflow Toolbar and click the Comment icon](/images/how-to-guides/how-to-add-a-comment-on-an-element/ACE1FINAL.png)
    </Frame>
  </Step>
  <Step title="After clicking the icon, click the Element you want to comment on">
    > **Note**: when you hover your cursor on an element, it will appear as a **Comment** icon which signifies that you selected the comment feature.

    <Frame>
    ![After clicking the icon, click the Element you want to comment on](/images/how-to-guides/how-to-add-a-comment-on-an-element/ACE2FINAL.png)
    </Frame>
  </Step>
  <Step title="The Comment Box will appear, enter your comment or type @ to add other users">
    > **Note**: the **Comment Box** lets you add users, attach files, record audio, record videos, and record screens.

    <Frame>
    ![The Comment Box will appear, enter your comment or type @ to add other users](/images/how-to-guides/how-to-add-a-comment-on-an-element/ACE3FINAL.png)
    </Frame>
  </Step>
  <Step title="Click the Post button to post your comment">
  </Step>
  <Step title="Once you click the Post button, a comment thread will appear on the selected element">
    <Frame>
    ![Once you click the Post button, a comment thread will appear on the selected element](/images/how-to-guides/how-to-add-a-comment-on-an-element/ACE4FINAL.png)
    </Frame>
  </Step>
</Steps>

---

In this article, you will learn how to add an arrow comment using the Superflow Toolbar.

<Steps>
  <Step title="Find the Superflow Toolbar and click the Arrows icon">
    <Frame>
    ![Find the Superflow Toolbar and click the Arrows icon](/images/how-to-guides/how-to-add-an-arrow-comment/AA1FINAL.png)
    </Frame>
  </Step>
  <Step title="Click the Element or Text where you want to point the arrow">
    <Frame>
    ![Click the Element or Text where you want to point the arrow](/images/how-to-guides/how-to-add-an-arrow-comment/AA2FINAL.png)
    </Frame>
  </Step>
  <Step title="The Arrow will appear on the selected area">
    You can move the arrow by clicking and dragging the arrow itself.

    <Frame>
    ![The Arrow will appear on the selected area](/images/how-to-guides/how-to-add-an-arrow-comment/AA3FINAL.png)
    </Frame>
  </Step>
  <Step title="You can adjust the arrow size by clicking the end point of the arrow…">
    You can adjust the arrow size by clicking the end point of the arrow and dragging it to achieve the preferred size.

    <Frame>
    ![You can adjust the arrow size by clicking the end point of the arrow…](/images/how-to-guides/how-to-add-an-arrow-comment/AA4FINAL.png)
    </Frame>
  </Step>
</Steps>

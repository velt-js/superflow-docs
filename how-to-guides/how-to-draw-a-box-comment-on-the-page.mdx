In this article, you will learn how to draw a box and create a comment thread on an element or a text.

<Steps>
  <Step title="Enter into the Comment Mode">
    See How to Enter/Exit Comment Mode.

    <Frame>
    ![Enter into the Comment Mode](/images/how-to-guides/how-to-draw-a-box-comment-on-the-page/DCB1FINAL.png)
    </Frame>
  </Step>
  <Step title="Find the area on the page where you want to draw a box comment">
    **Left Click** on the area, hold it, and drag the box to determine the box size.
  </Step>
  <Step title="After drawing the box, the Comment Box will appear…">
    After drawing the box, the **Comment Box** will appear, enter your comment or type @ to add other users.

    <Note>
    the **Comment Box** lets you add users, attach files, and record audio, videos, and screens.
    </Note>

    <Frame>
    ![After drawing the box, the Comment Box will appear…](/images/how-to-guides/how-to-draw-a-box-comment-on-the-page/DCB2FINAL.png)
    </Frame>
  </Step>

</Steps>

In this article, you will learn how to add private comments. This type of comment is not accessible to all users and requires Team credentials to read or respond.

<Steps>
  <Step title="Ensure that you are logged in to your Superflow account">
  </Step>
  <Step title="Find the Superflow Toolbar and click the Private Mode lock icon to enable this feature">
    <Frame>
    ![Find the Superflow Toolbar and click the Private Mode lock icon to enable this feature](/images/how-to-guides/how-to-add-private-comments/PM1FINAL.png)
    </Frame>
  </Step>
  <Step title="Enabling this mode will allow only the Team users to view your private comments">
    On the **Superflow Toolbar**, click the **Comment** icon.

    <Frame>
    ![Enabling this mode will allow only the Team users to view your private comments](/images/how-to-guides/how-to-add-private-comments/PM2FINAL.png)
    </Frame>
  </Step>
  <Step title="Click the area or an element where you want to comment privately">
    <Frame>
    ![Click the area or an element where you want to comment privately](/images/how-to-guides/how-to-add-private-comments/PM3FINAL.png)
    </Frame>
  </Step>
  <Step title="A Comment Box will appear">
    Enter the private comment and click the **Post** icon.

    <Frame>
    ![A Comment Box will appear](/images/how-to-guides/how-to-add-private-comments/PM4FINAL.png)
    </Frame>
  </Step>
</Steps>

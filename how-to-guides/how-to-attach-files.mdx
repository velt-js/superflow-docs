In this article, you will learn how to attach files to your comments. This comes in handy when you want to show or add a reference to what you would like to accomplish.

<Steps>
  <Step title="Find the Superflow Toolbar and click the Comment icon">
    <Frame>
    ![Find the Superflow Toolbar and click the Comment icon](/images/how-to-guides/how-to-attach-files/RVN1FINAL.png)
    </Frame>
  </Step>
  <Step title="After clicking the icon, click the Element you want to comment on">
    > **Note**: when you hover your cursor on an element, it will appear as a **Comment** icon which signifies that you selected the comment feature.

    <Frame>
    ![After clicking the icon, click the Element you want to comment on](/images/how-to-guides/how-to-attach-files/AF1FINAL.png)
    </Frame>
  </Step>
  <Step title="The Comment Box will appear, click the Attach Files icon">
    <Frame>
    ![The Comment Box will appear, click the Attach Files icon](/images/how-to-guides/how-to-attach-files/AF2FINAL.png)
    </Frame>
  </Step>
  <Step title="The File Location window will appear">
    Find and select the file to attach.
    > **Note**: this option only accepts image files such as png, jpg, gif, svg with less than 2MB file size.

    <Frame>
    ![The File Location window will appear](/images/how-to-guides/how-to-attach-files/AF3FINAL.png)
    </Frame>
  </Step>
  <Step title="Click Open to upload the file">
  </Step>
  <Step title="The selected file will appear in the Comment Box">
    You can add a description or a note in the comment field to include details of the attachment (optional). Click the **Post** button to comment with the attached file.

    <Frame>
    ![The selected file will appear in the Comment Box](/images/how-to-guides/how-to-attach-files/AF4FINAL.png)
    </Frame>
  </Step>
</Steps>

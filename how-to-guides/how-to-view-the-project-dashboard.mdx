In this article, you will learn how to access the Project Dashboard through the Superflow Toolbar. The Project Dashboard requires admin-level credentials as this page enables you to manage projects.

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/how-to-guides/how-to-view-the-project-dashboard/VPD1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Frame>
    ![A new tab will direct you to the Project Dashboard page](/images/how-to-guides/how-to-view-the-project-dashboard/VPD2FINAL.png)
    </Frame>
  </Step>
  <Step title="On this page, you will find the following features:">
    * Project Details (e.g. project URL, People, Pages, Views)
    * Manage Versions
    * Settings
    * Dashboard for Comment Status (e.g. Open, In Progress, Resolved)
  </Step>
  <Step title="You can also access the following modules:">
    * Website
    * Files
    * Users
    * Integrations
    * Help Videos
    * Contact Support
    * Join Community
  </Step>
</Steps>

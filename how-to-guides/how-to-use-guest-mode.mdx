To use the Guest Mode feature, you have to sign out from your Superflow account. Once you log out, the GUEST MODE will automatically kick in. When the guest mode is enabled, you can leave comments on the project even if you are not logged in to a Superflow account.

<Frame>
![To use the Guest Mode feature, you have to sign out from your Superflow account](/images/how-to-guides/how-to-use-guest-mode/GM1FINAL.png)
</Frame>

It is important to note, that to use the Guest Mode, it has to be enabled first. See Enabling Guest Mode (Admin) for more information.

<Frame>
![It is important to note, that to use the Guest Mode, it has to be enabled first](/images/how-to-guides/how-to-use-guest-mode/GM2FINAL.png)
</Frame>

### Enabling Guest Mode (Admin)

Enabling the guest mode is a required prerequisite to use this feature. You need to have admin credentials to access this option.

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/how-to-guides/how-to-use-guest-mode/VPD1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="You will be directed to the Project Dashboard page, find and click the Settings icon">
    <Frame>
    ![You will be directed to the Project Dashboard page, find and click the Settings icon](/images/how-to-guides/how-to-use-guest-mode/EGM1FINAL.png)
    </Frame>
  </Step>
  <Step title="Find the Manage Access & Permissions section and click the See More drop-down arrow">
    <Frame>
    ![Find the Manage Access & Permissions section and click the See More drop-down arrow](/images/how-to-guides/how-to-use-guest-mode/EGM2FINAL.png)
    </Frame>
  </Step>
  <Step title="The Manage Access & Permissions section will expand…">
    The **Manage Access & Permissions** section will expand, go to the **Guest Mode** option and ensure that it is turned on by toggling it to **Enable Guest Mode**.

    <Frame>
    ![The Manage Access & Permissions section will expand…](/images/how-to-guides/how-to-use-guest-mode/EGM3FINAL.png)
    </Frame>
  </Step>
</Steps>

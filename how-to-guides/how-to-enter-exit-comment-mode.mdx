In this article, you will learn how to enter/exit the Comment Mode. This mode enables you to manage comments.

<Steps>
  <Step title="Find the Superflow Toolbar and click the Comment icon to access the comment mode">
    <Frame>
    ![Find the Superflow Toolbar and click the Comment icon to access the comment mode](/images/how-to-guides/how-to-enter-exit-comment-mode/CM1FINAL.png)
    </Frame>
  </Step>
  <Step title="You will enter the Comment Mode as the browser indicates">
    When you enter the **Comment Mode**, you will be able to do the following:
    * Comment on Elements
    * Comment on Text
    * Comment on Images
    * Draw a Box Comment

    <Frame>
    ![You will enter the Comment Mode as the browser indicates](/images/how-to-guides/how-to-enter-exit-comment-mode/CM2FINAL.png)
    </Frame>
  </Step>
  <Step title="To exit the Comment Mode, press the ESC on your keyboard or click the esc to exit indicator on…">
    To exit the **Comment Mode**, press the **ESC** on your keyboard or click the **esc to exit** indicator on top of the browser.
  </Step>
</Steps>

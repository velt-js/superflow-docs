In this article, you will learn how to exit from the Review Mode.

<Steps>

    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/how-to-guides/how-to-exit-review-the-mode/ERM1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, select Exit Review Mode">
  </Step>
  <Step title="After selecting the Exit Review Mode option, you will immediately exit the review mode">
    The **Superflow Toolbar** will no longer be available.
  </Step>
</Steps>

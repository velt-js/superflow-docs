In this article, you will learn how to integrate Superflow with Slack.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>
  </Step>
  <Step title="Click the INTEGRATIONS module to access more integration options">
    <Frame>
    ![Click the INTEGRATIONS module to access more integration options](/images/integrations/how-to-integrate-with-slack/SL1FINAL.png)
    </Frame>
  </Step>
  <Step title="Select SLACK to access Slack’s integration page and click Connect to start the integration">
  </Step>
  <Step title="You will be directed to Slack’s integration page">
    In the **Workspace** field, enter the workspace’s URL and click **Continue**.

    <Frame>
    ![You will be directed to Slack’s integration page](/images/integrations/how-to-integrate-with-slack/SL2FINAL.png)
    </Frame>
  </Step>
  <Step title="You will be directed to the confirmation page…">
    You will be directed to the confirmation page, click **Allow** to allow Superflow to access the specified workspace.

    <Frame>
    ![You will be directed to the confirmation page…](/images/integrations/how-to-integrate-with-slack/SL3FINAL.png)
    </Frame>
  </Step>
</Steps>

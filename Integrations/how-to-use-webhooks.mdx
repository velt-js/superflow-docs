In this article, you will learn how to integrate Superflow with Webhooks.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>
  </Step>
  <Step title="Click the INTEGRATIONS module to access more integration options">
    <Frame>
    ![Click the INTEGRATIONS module to access more integration options](/images/integrations/how-to-use-webhooks/WH1FINAL.png)
    </Frame>
  </Step>
  <Step title="Select WEBHOOKS to access Webhooks’ integration page">
  </Step>
  <Step title="Click the Enable Webhooks Toggle bar to enable Webhooks services">
  </Step>
  <Step title="After enabling the Webhooks, a Confirmation message will appear that the Webhook service is…">
    After enabling the Webhooks, a **Confirmation** message will appear that the Webhook service is enabled.

    <Frame>
    ![After enabling the Webhooks, a Confirmation message will appear that the Webhook service is…](/images/integrations/how-to-use-webhooks/WH2FINAL.png)
    </Frame>
  </Step>
</Steps>

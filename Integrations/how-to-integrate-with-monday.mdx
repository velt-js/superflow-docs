In this article, you will learn how to integrate Superflow with Monday.com.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>
  </Step>
  <Step title="Click the INTEGRATIONS module to access more integration options">
    <Frame>
    ![Click the INTEGRATIONS module to access more integration options](/images/integrations/how-to-integrate-with-monday/IM1FINAL.png)
    </Frame>
  </Step>
  <Step title="Select MONDAY to access Monday.com’s integration page">
    Click the **Install App** button to start the integration.

    <Note>
    **IMPORTANT NOTE**: This is a required step before you can connect to Superflow with Monday.com. Ensure that Superflow is installed on Monday.com before connecting your Superflow account.
    </Note>
  </Step>
  <Step title="You will be directed to Monday.com’s integration page">
    In the **Workspace** section, select the workspace to use or add a new one using the **+ Add Workspace** button.

    <Frame>
    ![You will be directed to Monday.com’s integration page](/images/integrations/how-to-integrate-with-monday/IM2-3FINAL.png)
    </Frame>
  </Step>
  <Step title="Click the Install button">
    Once Superflow is successfully installed, you will be directed to Monday.com’s **Manage Apps** page.
  </Step>
  <Step title="Go back to the Integration tab and click the Connect button">
    <Frame>
    ![Go back to the Integration tab and click the Connect button](/images/integrations/how-to-integrate-with-monday/IM4FINAL.png)
    </Frame>
  </Step>
  <Step title="Review the details and click the Authorize button">
    <Frame>
    ![Review the details and click the Authorize button](/images/integrations/how-to-integrate-with-monday/IM5FINAL.png)
    </Frame>
  </Step>
</Steps>

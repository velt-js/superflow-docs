## Start with agents

Agents are reusable checks you describe in plain English. Superflow runs them against your projects and reports what it finds: spelling, broken links, accessibility, SEO, or anything else you can describe.

<Note>
  Agents are currently in **Beta**. QA agents and always-on monitoring are priced at **\$14 per site per month**. Every site gets automatic versioning, change detection, compare / diff, and run checks. Every change to the site is captured as a new version, with no set up needed, and QA agents check each change and flag if they find an issue.
</Note>

## Run Superflow from your AI assistant

The Superflow MCP server connects your workspace to Claude, ChatGPT, Cursor and Gemini. Once it is connected you can ask your assistant to run agents on a page, read back the findings, create projects and summarize open comments.

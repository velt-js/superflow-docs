In this article, you will learn how to create a new project from the Superflow Dashboard.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
  </Step>
  <Step title="By default, when accessing the Project Dashboard…">
    By default, when accessing the **Project Dashboard**, you will be directed to the Dashboard for Comment Status screen. To access the Projects list, click **< Back** or the **WEBSITES** module.

    <Frame>
    ![By default, when accessing the Project Dashboard…](/images/dashboard/how-to-create-a-new-project/CP1FINAL.png)
    </Frame>
  </Step>
  <Step title="Click the + Create Project button">
    <Frame>
    ![Click the + Create Project button](/images/dashboard/how-to-create-a-new-project/CP2FINAL.png)
    </Frame>
  </Step>
  <Step title="You will be directed to the Create new project page">
    Specify the required information.
  </Step>
  <Step title="In the Choose a platform to install Superflow section, click the drop-down arrow…">
    In the **Choose a platform to install Superflow** section, click the drop-down arrow, select the appropriate platform, and click **Next**.

    <Frame>
    ![In the Choose a platform to install Superflow section, click the drop-down arrow…](/images/dashboard/how-to-create-a-new-project/CP3FINAL.png)
    </Frame>
  </Step>
  <Step title="In the Where do you want to install Superflow section, enter the staging or production URL…">
    In the **Where do you want to install Superflow** section, enter the staging or production URL, and click **Next**.

    <Note>
    you can add multiple URLs using the **Add +** button.
    </Note>

    <Frame>
    ![In the Where do you want to install Superflow section, enter the staging or production URL…](/images/dashboard/how-to-create-a-new-project/CP4FINAL.png)
    </Frame>
  </Step>
  <Step title="In the Install Code Snippet section…">
    In the **Install Code Snippet** section, copy the snippet using the **Copy** icon and paste it on your website. Click **Next** to continue.

    <Frame>
    ![In the Install Code Snippet section…](/images/dashboard/how-to-create-a-new-project/CP5FINAL.png)
    </Frame>
  </Step>
  <Step title="In the Verify section, click the Test button to verify the installation">
    <Frame>
    ![In the Verify section, click the Test button to verify the installation](/images/dashboard/how-to-create-a-new-project/CP6FINAL.png)
    </Frame>
  </Step>
  <Step title="A new window/tab will open indicating that the snippet was installed successfully, click Next">
    <Frame>
    ![A new window/tab will open indicating that the snippet was installed successfully, click Next](/images/dashboard/how-to-create-a-new-project/CP7FINAL.png)
    </Frame>
  </Step>
  <Step title="Once the testing stage is completed…">
    Once the testing stage is completed, you will be directed to the **Add Guest Users** section to add Guest users to your new project.
  </Step>
</Steps>

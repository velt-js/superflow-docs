In this article, you will learn how to create a new project from the Superflow Dashboard at [app.usesuperflow.com](https://app.usesuperflow.com).

<Steps>
  <Step title="On the Home page, click Create Project">
    The **New Project** page opens, with the wizard steps shown across the top: **Create Project**, **Install**, **Verify**, and **Invite your Team**.
  </Step>
  <Step title="Paste your website URL and click Start">
    To review a file instead of a website, use the **Figma**, **Videos**, **Images**, **Lottie** or **PDF** buttons below the URL field. See [How to Upload a File](/files/how-to-upload-a-file).

    <Frame>
    ![The New Project page with the website URL field, Run agents option, and file type buttons](/images/dashboard/how-to-create-a-new-project/01-new-project-card.png)
    </Frame>

    <Tip>
    Leave **Run agents** checked and pick agents to have Superflow start reviewing the site for spelling, broken links, accessibility and more while you finish the install. Check **Run agents on every page** to crawl the whole site instead of just this URL. See [agent pre-checks](/agents/how-to-run-agent-pre-checks-on-a-new-project).
    </Tip>
  </Step>
  <Step title="Install the script on your site">
    Pick your platform at the top of the install card: **HTML** (copy the raw snippet), **WordPress**, **Webflow**, **Google Tag Manager**, **Shopify**, or **Framer**. **Other Guides** covers Elementor, Wix, Bubble, HubSpot, Squarespace, Drupal and more. The right side shows a live preview of your site with the toolbar already on it.

    <Frame>
    ![The Install step with platform options, the script snippet, and a live preview of the site](/images/dashboard/how-to-create-a-new-project/02-install-script.png)
    </Frame>

    <Tip>
    Not the person who edits the site? Click **Send to Developer** to email the setup steps, then use **Save & finish later**.
    </Tip>
  </Step>
  <Step title="Click Next: Verify">
    Superflow checks your published site every few seconds and confirms as soon as the script is live. If it cannot verify, make sure the site is published and publicly reachable.
  </Step>
  <Step title="Invite your team">
    Add teammates or clients by email, then click **Go to Project**. You can always invite more people later from the [Users page](/dashboard/how-to-invite-users-to-your-project).
  </Step>
</Steps>

Your new project appears on the Home page. Open the site with `?review=true` at the end of the URL to start commenting.

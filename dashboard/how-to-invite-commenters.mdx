In this article, you will learn how to invite Guest users to your project. The Guest user type will let you comment on the projects which you were invited.

As a Guest user, your account’s functionality and access to features is limited compared to the Team level credentials.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>
  </Step>
  <Step title="Click the USERS module to access the Users page">
    <Frame>
    ![Click the USERS module to access the Users page](/images/dashboard/how-to-invite-admin-users/IU1FINAL.png)
    </Frame>
  </Step>
  <Step title="Find and click the + Invite Users button">
    <Frame>
    ![Find and click the + Invite Users button](/images/dashboard/how-to-invite-admin-users/IU2FINAL.png)
    </Frame>
  </Step>
  <Step title="The Invite Users dialog box will appear">
    In the **Email** field, enter the user’s email address.
  </Step>
  <Step title="Click the Drop-Down menu and select Guest">
    <Frame>
    ![Click the Drop-Down menu and select Guest](/images/dashboard/how-to-invite-commenters/IC1FINAL.png)
    </Frame>
  </Step>
  <Step title="Additional fields will appear">
    In the **Project Name** field, enter the project name or use the drop-down arrow to select the project you want to invite the Guest user to.

    <Note>
    you can use the project link using the Copy project link button and provide it to the Guest user to access.
    </Note>

    <Frame>
    ![Additional fields will appear](/images/dashboard/how-to-invite-commenters/IC2FINAL.png)
    </Frame>
  </Step>
  <Step title="After entering and defining the required credentials, click the Send invites button">
  </Step>
</Steps>

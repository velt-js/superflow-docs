In this article, you will learn how to use the Kanban Board.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>

    Three (3) columns display the comment statuses namely; (a) Open, (b) In Progress, and (c) Resolved.

    <Frame>
    ![A new tab will direct you to the Project Dashboard page](/images/dashboard/how-to-use-the-kanban-board/KB1FINAL.png)
    </Frame>
  </Step>
</Steps>

Individual boxes represent a comment from your project which is categorized by its status.

You can move these boxes to the appropriate Column (e.g. Open, In Progress, Resolved) by **Dragging** and **Dropping** them to the target column.

<Frame>
![You can move these boxes to the appropriate Column (e.g. Open, In Progress, Resolved) by Dragging…](/images/dashboard/how-to-use-the-kanban-board/KB2FINAL.png)
</Frame>

To reply to a comment within the board, click the **Reply** button inside its box.

<Frame>
![To reply to a comment within the board, click the Reply button inside its box](/images/dashboard/how-to-use-the-kanban-board/KB3FINAL.png)
</Frame>

You can also go to the project’s actual comment by clicking the **Go to Comment** icon which will open a new tab that directs you to the project where the comment was added.

<Frame>
![You can also go to the project’s actual comment by clicking the Go to Comment icon which will open…](/images/dashboard/how-to-use-the-kanban-board/KB4FINAL.png)
</Frame>

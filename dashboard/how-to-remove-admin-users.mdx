In this article, you will learn how to remove admin users from your Superflow Account and the relevant projects.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, when accessing the **Project Dashboard**, you will be directed to the Dashboard for Comment Status screen.
    </Note>
  </Step>
  <Step title="Click the USERS module to access the Users page">
    <Frame>
    ![Click the USERS module to access the Users page](/images/dashboard/how-to-invite-admin-users/IU1FINAL.png)
    </Frame>
  </Step>
  <Step title="Go to the Admins section and find the admin user that you want to remove">
  </Step>
  <Step title="Click the More Options icon and select Delete">
    <Note>
    **IMPORTANT NOTE**: ensure to select the correct user as there is no confirmation dialog box to confirm the action. Once you click **Delete**, the admin user will be deleted immediately.
    </Note>

    <Frame>
    ![Click the More Options icon and select Delete](/images/dashboard/how-to-remove-admin-users/RA1FINAL.png)
    </Frame>
  </Step>
</Steps>

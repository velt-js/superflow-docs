title: "How to Access the Project Settings"
description: "Learn how to access the project settings."
icon: "gear"
---

In this article, you will learn how to access the project settings. The Project Settings enable you to specify more project details, manage permissions, define project configuration, migrate Superflow data to another URL, access unique code, and view usage.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the *View Project option to select">
    <Frame>
    ![A sub-menu will expand, click the *View Project option to select](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
  </Step>
  <Step title="By default, when accessing the Project Dashboard…">
    By default, when accessing the **Project Dashboard**, you will be directed to the **Dashboard for Comments Status** screen or the Kanban Board. To access the Projects list, click the **< Back** or the **WEBSITES** module.

    <Frame>
    ![By default, when accessing the Project Dashboard…](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/PS1FINAL.png)
    </Frame>
  </Step>
  <Step title="In the All Projects list, find the project you want to view and click its More Options icon">
    <Frame>
    ![In the All Projects list, find the project you want to view and click its More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/PS2FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click Settings to select">
  </Step>
  <Step title="The Project Settings enable you to do the following:">
    - Add/Update Project Name
    - Add/Edit Client Name
    - Manage Access & Permissions
    - Manage URLs
    - Access Unique Code
    - Migrate Superflow Data to another URL
    - View Usage

    <Frame>
    ![The Project Settings enable you to do the following:](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/PS3FINAL.png)
    </Frame>
  </Step>
</Steps>

---
title: "How to Invite Users to your Project"
description: "Learn how to invite users to your project."
icon: "user-plus"
---

In this article, you will learn how to invite users to your project. There are two (2) types of users, the Admin and Commenters. It is worth noting that these types of users have different functions and access to features.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>
  </Step>
  <Step title="Click the USERS module to access the Users page">
    <Frame>
    ![Click the USERS module to access the Users page](/images/dashboard/how-to-invite-users-to-your-project/IU1FINAL.png)
    </Frame>
  </Step>
  <Step title="Find and click the + Invite Users button">
    <Frame>
    ![Find and click the + Invite Users button](/images/dashboard/how-to-invite-users-to-your-project/IU2FINAL.png)
    </Frame>
  </Step>
  <Step title="The Invite Users dialog box will appear">
    In the **Email** field, enter the user's email address.

    <Frame>
    ![The Invite Users dialog box will appear](/images/dashboard/how-to-invite-users-to-your-project/IU3FINAL.png)
    </Frame>
  </Step>
  <Step title="Defind the user type by clicking the Drop-Down Menu and selecting the appropriate type:">
    - **Admin**: this user type can comment on all projects and has access to the portal.
    - **Commenter**: this user type can only comment on this project and does not have access to the portal.
  </Step>
  <Step title="After entering and defining the required credentials, click the Send invites button">
    <Frame>
    ![After entering and defining the required credentials, click the Send invites button](/images/dashboard/how-to-invite-users-to-your-project/IU4FINAL.png)
    </Frame>
  </Step>
</Steps>

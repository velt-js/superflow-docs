The server offers **101 tools**: 45 that only read and 56 that change data. You never call them yourself. Ask in plain words and your assistant picks the right ones. Use this page to choose [permissions](/mcp/api-keys-and-permissions) and to see what a request can do.

Wherever a tool asks for a project, page, person or comment, you can give a name, a site URL, an email or a link.

<Note>
  Tools marked **asks first** show a preview and change nothing until you agree. See [what asks you first](/mcp/safety-and-limits).
</Note>

## Playbooks

Step-by-step plans for jobs that take several tools in order. The assistant fetches one and follows it.

| Tool | What it does | Permission |
| --- | --- | --- |
| `superflow_use_playbook`<br/>Get a playbook | Gets a step-by-step plan for a job that takes several tools in order, and the model follows it: `triage` (what is broken on a site, as one ordered P0, P1, P2 list), `fix` (fix the approved items, have a rescan verify each, report), `push_my_review` (push your own review's findings in) and `onboard_agency` (a first client site, checked on a schedule). Nothing to install: the server serves them. *Reads only.* | Any key |

## Checks

A check is one kind of problem the review agents look for, such as broken links or missing alt text. Each check groups its open findings across the site.

| Tool | What it does | Permission |
| --- | --- | --- |
| `superflow_list_failing_checks`<br/>List a site's failing checks | The failing checks of a site, worst first: severity, open findings, pages, owner and how many score points fixing it is worth. *Reads only.* | Read comments |
| `superflow_get_check_details`<br/>Get one check and its findings | One check: its fix guide and its open findings with their pages and links, 20 at a time. *Reads only.* | Read comments |
| `superflow_get_site_score`<br/>Get a site's score | The site score, the runs before it, and the lowest scoring pages. *Reads only.* | Read comments |
| `superflow_get_finding_source`<br/>Find a finding in the page's HTML | The line of stored HTML a finding points at, to find it in the code. *Reads only.* | Read comments |
| `superflow_mark_check_fixed`<br/>Mark a check fixed | Resolves every open finding of a check and has a rescan verify it (1 credit). Needs `confirm: true`; without it the tool shows what it would resolve. *Changes data, asks first, spends AI credits.* | Read comments, Edit comments |
| `superflow_exclude_check`<br/>Exclude a check for a site | Turns a check off for a site, with a reason. Needs `confirm: true`. *Changes data, asks first.* | Read comments, Edit comments |
| `superflow_include_check`<br/>Include an excluded check | Turns an excluded check back on. *Changes data.* | Edit comments |
| `superflow_assign_check_owner`<br/>Assign a check's owner | Sets who owns a check, or back to the default owner. *Changes data.* | Edit comments |
| `superflow_reject_comment`<br/>Reject an agent finding | Rejects an agent finding as wrong, not important, not applicable or cannot tell. It cannot be undone, so it needs `confirm: true`; without it the tool shows the finding. *Changes data, asks first, cannot be undone.* | Read comments, Edit comments |
| `superflow_get_check_settings`<br/>Get a site's check settings | The confidence floor and the default owners for content, design and dev checks. *Reads only.* | Read projects |
| `superflow_set_default_owners`<br/>Set a site's default owners | Sets the default owners for content, design and dev checks. *Changes data.* | Read projects, Create and update projects |

## Site settings

How a site is monitored, when scheduled checks run, and which forms get tested.

| Tool | What it does | Permission |
| --- | --- | --- |
| `superflow_get_site_monitoring`<br/>Get a site's monitoring mode | Whether a site is in care (agents run on a schedule) or watch (Version history only), with the cadence, time zone and the run in progress. *Reads only.* | Read projects |
| `superflow_set_site_mode`<br/>Set a site's monitoring mode | Moves a site to care or watch. care runs agents and spends AI credits, so it needs `confirm: true`; on a site never monitored it starts a full check now. *Changes data, asks first, spends AI credits.* | Read projects, Create and update projects |
| `superflow_set_site_timezone`<br/>Set a site's time zone | The time zone scheduled checks and Version history captures run in. *Changes data.* | Create and update projects |
| `superflow_list_forms`<br/>List a site's forms | The forms the Forms agent found on a site, with their test settings and last result. *Reads only.* | Read projects |
| `superflow_set_form_testing`<br/>Turn a form's test on or off | Turns a form's test on or off. On needs `confirm: true`: each test lands in the client's inbox as a lead. *Changes data, asks first.* | Read projects, Create and update projects |

## Import findings

Bring the results of your own review, from your own prompts or agent, into Superflow.

| Tool | What it does | Permission |
| --- | --- | --- |
| `superflow_import_findings`<br/>Import findings from your own agent | Pushes the findings of your own review (your prompts, your agent) into Superflow. Each becomes an agent comment pinned on its page under your agent's name, and merges with the same finding next time. They are not checks: the failing checks and the fix list do not include them. Up to 500 per call, 5,000 per project per day. Needs the `ingest` scope. *Changes data.* | Import findings |

## API keys

Keys for CI or other tools. The token is shown once.

| Tool | What it does | Permission |
| --- | --- | --- |
| `superflow_list_api_keys`<br/>List API keys | Your own keys and app sign-ins in this workspace. Never the tokens. *Reads only.* | Read workspace |
| `superflow_create_api_key`<br/>Create an API key | A new key for CI or another tool. Needs an API key with `workspace:write` (a sign-in cannot create keys); scopes must be ones the current key has, and it cannot outlive it. Needs `confirm: true`; the preview says first when the key cannot be created. The token is shown once, in the conversation. *Changes data, asks first.* | Manage workspace settings |
| `superflow_revoke_api_key`<br/>Revoke an API key | Revoke a key or sign-in. Needs `confirm: true`. *Changes data, asks first.* | Read workspace, Manage workspace settings |

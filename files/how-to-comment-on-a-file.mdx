In this article, you will learn how to comment on a file using the dashboard.

Access the Superflow Dashboard by going to [app.usesuperflow.com](app.usesuperflow.com). Alternatively, when you are in Review Mode, you can use the method below:

<Steps>
  <Step title="Find the Superflow Toolbar and click the More Options icon">
    <Frame>
    ![Find the Superflow Toolbar and click the More Options icon](/images/dashboard/how-to-access-project-settings/how-to-access-project-settings/INT1FINAL.png)
    </Frame>
  </Step>
  <Step title="A sub-menu will expand, click the View Project option to select">
  </Step>
  <Step title="A new tab will direct you to the Project Dashboard page">
    <Note>
    By default, you will be directed to the Dashboard for Comment Status screen when accessing the **Project Dashboard**.
    </Note>
  </Step>
  <Step title="Click the FILES module to access the Files page">
    <Frame>
    ![Click the FILES module to access the Files page](/images/files/how-to-comment-on-a-file/CF1FINAL.png)
    </Frame>
  </Step>
  <Step title="Find the file and click its Review Link icon">
    <Frame>
    ![Find the file and click its Review Link icon](/images/files/how-to-comment-on-a-file/CF2FINAL.png)
    </Frame>
  </Step>
  <Step title="On the Superflow Toolbar, click the Comments icon to enable the Comment Mode">
    <Frame>
    ![On the Superflow Toolbar, click the Comments icon to enable the Comment Mode](/images/files/how-to-comment-on-a-file/CF3FINAL.png)
    </Frame>
  </Step>
  <Step title="Point and click the area on the file that you want to comment on">
  </Step>
  <Step title="In the Comment field, enter your comment and click the Send icon">
    <Frame>
    ![In the Comment field, enter your comment and click the Send icon](/images/files/how-to-comment-on-a-file/CF4FINAL.png)
    </Frame>
  </Step>
</Steps>

title: "How to Use Versions and Approve a File"
description: "Every file keeps a version history. Switch between versions, rename them, and approve the one that is final."
icon: "circle-check"
---

Every uploaded file in Superflow keeps a version history, so "final_v3_FINAL.pdf" never has to happen again. When a round of feedback is done, upload the revised file as a new version, and approve the version everyone agreed on.

## Working with versions

<Steps>
  <Step title="Open the file from your dashboard">
    File projects open in the Superflow file viewer in a new tab.
  </Step>
  <Step title="Use the version dropdown in the header">
    The dropdown next to the file name lists every version. Switch versions to see the file and the comments that belong to that round of review. You can rename versions to something meaningful, like "Round 2" or "Post client call".
  </Step>
</Steps>

## Approving

<Steps>
  <Step title="Click the approval button in the header">
    The header shows **NOT APPROVED** until someone approves the file. Click it to approve the version you are viewing; it flips to **Approved** for everyone.
  </Step>
</Steps>

Both Admins and commenters can approve, so your client can give the sign-off themselves, right from the review link.

<Note>
Approving a version does not lock the file. It is a signal of sign-off, and you can still add versions afterwards if things change.
</Note>

<Tip>
The file viewer's settings menu also lets you **Duplicate**, **Archive** or **Switch File** without going back to the dashboard.
</Tip>

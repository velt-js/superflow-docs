<Update label="August 5, 2026" description="Aug 1–5, 2026">
  ## Figma for everyone, plus an MCP connector for AI assistants

  ### New Features

  - **Figma import for everyone**: Figma project import is now available to every account, with no unlock step required — the asset picker, project wizard, and Settings integration tab are open to all.
  - **MCP connector for AI assistants**: Connect Claude, ChatGPT, Cursor, or Gemini CLI to a project through an OAuth-based MCP connector. The Settings page provides a server URL and setup steps, and a consent screen lets you grant invite-sending separately from read/write access.

  ### Improvements

  - The production SDK now uses a fixed stable version instead of a beta build.
  - Workspaces can now be restricted when plan limits or usage thresholds are exceeded, including deletion controls tied to plan status.

  ### Bug Fixes

  - Fixed the Figma drive viewer so the frame list no longer scrolls sideways and the frame stage fills the available width.
  - Fixed an issue where expanding the guides panel could collapse or clip the findings summary card.
</Update>

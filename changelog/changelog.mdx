<Update label="September 20, 2026" description="Sep 6-20, 2026">
  ## Smarter reports, direct integrations, and precise scans

  ### New Features

  - **Weekly QA feedback trend reports**: Ask AI can generate a one-off or recurring weekly report on QA trends, including top issues, project breakdowns, and a comments-per-week chart — viewable in-app or downloadable as a PDF.
  - **Slack notifications for scheduled reports**: A scheduled QA trends report can post to a Slack channel using your workspace's existing Slack connection, with each run showing whether the post succeeded.
  - **Send findings to Jira, Asana, Monday, ClickUp, or Slack from approvals**: A new approvals step can create a task in Jira, Asana, Monday, or ClickUp, or post a message to Slack, using accounts already connected in Settings.
  - **Run a scan against a specific list of pages**: The run modal now accepts a pasted list of page paths, so Superflow scans exactly those pages instead of crawling the whole site.
  - **Stop in-progress Ask AI answers**: The send button becomes a Stop control while an answer streams. Stopping ends generation and keeps the partial answer as a message.

  ### Improvements

  - The in-app report view now matches the downloaded PDF, showing scope, top issues, a projects table, trends, and recommendations, with support for diagrams and dividers in report text.
  - Reports now state the exact time window they cover and note how many test or placeholder comments were excluded.
  - Connected apps management moved from Workflows into Settings, and the redesigned integrations page now covers seven workflow apps.
  - When site size can't be determined, the run modal quotes a small-site page limit and shows the corresponding credit cost instead of an unrelated page count.

  ### Bug Fixes

  - Fixed report-ready email links to open in the workspace that generated the report, even when it differs from your default workspace.
  - Fixed the comments filter and executions sidebar to track each query-string variant of a page separately, instead of collapsing them into one entry.
</Update>

<Update label="September 6, 2026" description="Aug 23-Sep 6, 2026">
  ## Generate Reports, credit-based scan pricing, Jira for everyone, and one-click workflows

  ### New Features

  - **Generate Reports with Ask AI**: Ask Superflow for a breakdown of your QA process — reports surface the patterns in it, so you can see what to optimize in your workflow.
  - **Credit-based pricing for site scans**: Running a scan now shows a live credit quote before you start, reflecting whether you're scanning one page or the whole site. The billing page shows a scan rate breakdown, and usage history has scan-specific labels.
  - **Jira integration generally available**: The Jira integration is now open to every user, not just an internal group, across both approvals and settings.
  - **One-click workflow templates**: A new Templates tab installs pre-built workflows in one click. The first template connects Jira issue updates to an automated spell-check and UAT review, and writes pass or fail labels back to the Jira issue.
  - **Single sign-on for site access**: Project settings now support SAML single sign-on for gated sites, with a distinct status when a service account needs an MFA exemption.
  - **In-app bug reporting**: Report a bug from the toolbar or a modal within the product. Reports capture diagnostic context automatically, are redacted before submission, and are routed for review — available to every signed-in user, including the keyboard shortcut.
  - **What's New feed and sidebar announcement**: A dismissible sidebar card surfaces the latest update headline and links to the full What's New feed, alongside the notification button. Feed entries can show a tag for their feature area.
  - **Mobile-responsive portal**: The portal now works on phone and tablet screen widths. Navigation moves to a bottom bar, onboarding steps stack into one column, and the workflow canvas editor shows a desktop-only message below a minimum width.

  ### Improvements

  - Redesigned the approval workflow builder with updated node cards, consistent group sizing, clearer loading states, and title-case step-type labels.
  - The onboarding header now shows your upcoming step instead of a generic skip link, and the save-review step opens as a centered dialog reachable from anywhere in the flow. Agents that find no issues now show a clear all-clear indicator instead of a zero count.
  - Redesigned the onboarding install step to show platform options as a tab strip in one card, replacing the separate circular tiles used before.
  - Site-scan entries in usage history now show the same page list as other rows, so you can expand details instead of seeing a bare credit amount.
  - The projects table is now sortable by name, ascending or descending, by clicking the column header.

  ### Bug Fixes

  - Fixed scan quotes for projects whose stored URL omits a scheme, which previously caused underestimated page counts and prices.
  - Fixed the Comments Added stat in team analytics to count comments only, instead of all interactions.
</Update>

<Update label="August 16, 2026" description="Aug 2-16, 2026">
  ## Real-feeling previews, a proper agent workspace, and more ways to install

  ### New Features

  - **Cross-page preview navigation**: Visitors reviewing a site through a shared preview link can click through to other pages in the preview instead of being stuck on a single page.
  - **Workspace Agent**: A built-in Workspace Agent now appears in the agents list with its own page for tracking checklist progress. It unlocks automatically once your workspace has enough review rules.
  - **MCP connector for AI assistants**: Connect AI tools such as Claude, ChatGPT, Cursor, and Gemini CLI to your workspace over OAuth to access project data, with a consent screen and setup instructions in settings.
  - **Framer install**: Install the toolbar on a Framer site straight from the portal by pasting your project link and API key, alongside the existing plugin-based flow.
  - **Danger Zone in project settings**: Project deletion and a new Delete All Comments action now live in a dedicated Danger Zone, each behind a confirmation step.
  - **Deep-linked findings**: Opening a finding from agent results jumps straight to its comment on the reviewed page.
  - **Leave a workspace**: If you belong to more than one workspace, you can leave one directly from the workspace switcher, with a confirmation step first.
  - **Figma import for everyone**: Figma project import is now available on all accounts, with no early-access restriction.

  ### Improvements

  - The agents list and review checklist use a new table layout with sorting, category tagging, inline rule editing, and clearer utilization indicators for each rule.
  - The agents list can be sorted by last used or usage, and the agent picker on the new project page lists agents alphabetically in a larger scroll area.
  - The preview review card shows a loading placeholder while results are gathered, and says clearly when no automated checks ran.
  - Creating a project now succeeds even when the target site blocks automated detection.
  - When a site can't be reached during install verification, the portal shows a clear message and stops retrying instead of polling indefinitely.
  - The sidebar on the new project screen can be expanded and collapsed like everywhere else in the app.
  - Kanban status columns all render at the same width, no matter how much content a card holds.
  - Settings navigation returns you to the page you came from.
  - The arrow tool is no longer offered as a creation option in the toolbar. Existing arrow annotations still display as before.
  - Deletion actions now respect plan status and usage limits.

  ### Bug Fixes

  - Fixed an issue where clicking continue again during sign-in after successful code verification could show a code expired error.
  - Fixed project and comment status filters returning results that disagreed with what was shown on screen.
  - Fixed pages failing to load shortly after an update, which previously required a manual refresh.
  - Fixed projects that already have comments showing as Not Installed in the project list.
  - Fixed the close button and Go Back action on the kanban status change modal.
  - Fixed the Show Comments on Page toggle so it hides all comment pins and highlights, not just the minimap markers.
  - Fixed agent-driven comment checks so they detect and navigate to the current page when the site is accessed through a proxy.
  - Fixed the Figma review layout so the frame view uses the full available width.
  - Fixed the Open-in-Mobile QR code so it loads on the first click.
</Update>
